# Long Short-Term Memory
**Hochreiter & Schmidhuber, Neural Computation 9(8):1735-1780, 1997** · **Key:** `lstm1997` · **OpenAlex citations:** 134075 · **Era:** dl
**Read status:** full text (extraction has some garbled math symbols in Sections 3 and A.1; reconstructed carefully from context). Appendix A.2 and Tables 10-11 only skimmed.

## 1. Problem and motivation
Recurrent nets trained by BPTT or RTRL learn slowly or not at all when relevant input and target are separated by long time lags, because backpropagated error either blows up or vanishes exponentially with the lag (Sec. 1, Hochreiter 1991 analysis in Sec. 3.1). Alternatives (time delays, time constants, Ring's units, chunkers, etc.; Sec. 2) work only for short lags, need fine tuning, or need compressible input.

## 2. Core idea in one paragraph
Give each memory unit a self-loop with weight exactly 1.0 and a linear activation, so the error that flows through it is neither shrunk nor amplified (the "constant error carrousel", CEC). Then protect that stored value with two learned multiplicative "gates": an input gate decides when new input may write to the cell, and an output gate decides when the cell may influence the rest of the net. Learning uses a truncated gradient that does not push error out of the cell to earlier time steps except through the CEC. Think of a notebook page that is never erased by itself, plus a clerk who learns when to write and when to read.

## 3. The mathematics
**Error propagation through time (Sec. 3.1, eq. 2):**
$$\frac{\partial\vartheta_v(t-q)}{\partial\vartheta_u(t)}=\sum_{l_1=1}^{n}\cdots\sum_{l_{q-1}=1}^{n}\prod_{m=1}^{q} f'_{l_m}(net_{l_m}(t-m))\,w_{l_m l_{m-1}},\quad l_q=v,\ l_0=u$$
| Symbol | Meaning |
|---|---|
| $\vartheta_u(t)$ | error signal at unit $u$, time $t$ |
| $q$ | number of steps back in time |
| $f'$, $net$, $w$ | activation derivative, net input, weight |
| $n$ | number of units |

If every factor $|f'w|>1$ the error grows exponentially in $q$; if $<1$ it vanishes. For the logistic sigmoid $\max f'=0.25$, so with $|w|<4.0$ the error vanishes (text after eq. 2).

**Constant error flow (Sec. 3.2):** to keep error constant through a single self-connected unit $j$ one needs $f_j'(net_j(t))\,w_{jj}=1.0$, which forces $f_j$ linear and $w_{jj}=1.0$ (the CEC). The gates fix the input/output weight conflicts of this naive unit.

**Memory cell (Sec. 4):**
$$y^{c_j}(t)=y^{out_j}(t)\,h\big(s_{c_j}(t)\big),\qquad s_{c_j}(0)=0,\quad s_{c_j}(t)=s_{c_j}(t-1)+y^{in_j}(t)\,g\big(net_{c_j}(t)\big)$$
| Symbol | Meaning |
|---|---|
| $s_{c_j}$ | internal state of cell $j$ (the CEC) |
| $y^{in_j}, y^{out_j}$ | input and output gate activations, each $=f(\sum_u w\,y_u(t-1))$ |
| $g,h$ | squashing functions, ranges $[-2,2]$ and $[-1,1]$ in the experiments (A.1 eqs 4-5) |

The state is an additive accumulator (weight 1 on its own past), so $\partial s(t)/\partial s(t-1)=1$ and error neither vanishes nor explodes inside the cell. Note: this original version has no forget gate.

**Truncation (Sec. 4, A.1):** derivatives of the gate and cell net inputs with respect to earlier unit outputs are replaced by zero ("tr" signs), so error is not propagated out of cells/gates to earlier steps; only the weights adjacent to them are updated. This yields $O(W)$ cost per step and is local in space and time.

## 4. Method / architecture / algorithm
1. Network: input layer, one fully connected hidden layer of memory-cell blocks (S cells sharing one input and one output gate) plus gate units, optionally conventional hidden units, and an output layer (Sec. 4, Fig. 2).
2. Forward pass per eqs (6)-(9) in A.1; gates use logistic sigmoid, on-line learning.
3. Backward pass: a variant of RTRL with the truncation above.
4. Practical fixes: negative initial output-gate bias to avoid the "abuse problem" (cells used as bias cells); initial input-gate bias towards zero against internal-state drift (Sec. 4).
5. Typical settings: weights in $[-0.2,0.2]$ or $[-0.1,0.1]$, learning rates 0.01 to 1.0 depending on task (Sec. 5).

## 5. Achievements
- Exp. 1, embedded Reber grammar (Table 1): LSTM succeeded in 97-100% of trials, with 8,440 to 39,740 sequence presentations; RCC 50% success (182,000), Elman net 0% (>200,000).
- Exp. 2a (Table 2): at lag $p=100$, RTRL and BPTT 0% success (>5,000,000 sequences); chunker 33% (32,400); LSTM 100% (5,040).
- Exp. 2c (Table 3): minimal lag $q+1=1001$ with 1,000 distractor symbols solved, 49,000 sequences (mean of 20 trials); "no other recurrent net algorithm" solves it, per the authors.
- Exp. 4 adding problem (Table 7): $T=1000$ (minimal lag 500), 853,000 sequences, 1 wrong of 2560. Exp. 5 multiplication (Table 8) and Exp. 6 temporal order (Table 9: 6a 31,390; 6b 571,100 sequences) also solved.
- Abstract claims bridging minimal lags in excess of 1000 steps and many more successful runs than RTRL, BPTT, RCC, Elman nets, Neural Sequence Chunking.

## 6. Limitations
**Stated by the authors (Sec. 6):** truncated LSTM will not easily solve "strongly delayed XOR" problems (non-decomposable); like a feedforward net seeing the whole input, it can fail on tasks such as 500-step parity that random weight guessing solves; no precise counting of discrete time steps (99 vs 100 steps ago); extra units per block (up to a factor 9 more weights than a standard RNN with the same number of hidden units, 32 in the fully connected case); internal state drift and the abuse problem need workarounds; the authors say real-world applicability is still to be tested (Sec. 7, future work). Exp. 3a (Table 4) admits random guessing beats LSTM on that simple task.
**Seen in hindsight (hindsight):** all experiments are artificial; no forget gate (added later), so cell state cannot be reset in continuing streams; strictly sequential computation limits parallelism on hardware; very long contexts still harder than with attention.

- **Builds on:** `rumelhart1986` (BPTT/RTRL gradients), Hochreiter 1991 vanishing-gradient analysis, Mozer's time constants, Schmidhuber's chunkers.
