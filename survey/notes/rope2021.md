# RoFormer: Enhanced Transformer with Rotary Position Embedding
**Su, Lu, Pan, Murtadha, Wen, Liu (Zhuiyi Technology); arXiv:2104.09864v5 (Nov 2023 version; first posted April 2021)** · **Key:** `rope2021` · **OpenAlex citations:** 7633 · **Era:** tf
**Read status:** full text

## 1. Problem and motivation
Self-attention by itself is position-agnostic, so Transformers must be told token order. Standard options either add an absolute position vector to the input (sinusoidal in `transformer2017`, learned in `bert2018`), or modify the attention score with relative-position terms or biases (Shaw et al., Transformer-XL, T5, DeBERTa; Eqs. 5-10). The authors observe that these methods all work by adding position information to the context representation, which (they argue) makes them incompatible with linear self-attention, and they offer no clean decay of dependency with distance (Sec. 1).

## 2. Core idea in one paragraph
Instead of adding a position vector, rotate. Pair up the coordinates of each query and key vector into 2D planes and rotate the pair in its plane by an angle proportional to the token's position index. The dot product between a rotated query at position $m$ and a rotated key at position $n$ then depends only on the content and the offset $m-n$: absolute position is encoded by the rotation, but relative position emerges automatically in the attention score. Analogy: clock hands set to different times; the angle between two hands depends only on the time difference, not on the absolute times.

## 3. The mathematics
**(a) Requirement (Eq. 11):** find $f_q,f_k$ such that
$$\langle f_q(\mathbf x_m,m),\,f_k(\mathbf x_n,n)\rangle=g(\mathbf x_m,\mathbf x_n,m-n)$$
$\mathbf x_m,\mathbf x_n$ are token embeddings at positions $m,n$; $f_q,f_k$ produce position-aware query/key; $g$ may depend on position only through $m-n$.

**(b) 2D solution (Eqs. 12-13, derived in Sec. 3.4.1):**
$$f_q(\mathbf x_m,m)=(W_q\mathbf x_m)e^{im\theta},\quad f_k(\mathbf x_n,n)=(W_k\mathbf x_n)e^{in\theta},\quad g=\mathrm{Re}\big[(W_q\mathbf x_m)(W_k\mathbf x_n)^*e^{i(m-n)\theta}\big]$$
$W_q,W_k$ are the query/key projections, $\theta\ne0$ a preset constant, $(\cdot)^*$ complex conjugate, $\mathrm{Re}$ the real part. Derivation sketch: write $f$ and $g$ in polar form; require equal radii (so the radial part cannot depend on position, Eq. 27) and that the angle difference depends only on $n-m$; then the angle must be an arithmetic progression in position, $\phi(m)=m\theta+\gamma$ (Eqs. 28-30), with $\gamma$ set to 0.

**(c) General form (Eqs. 14-16):**
$$f_{\{q,k\}}(\mathbf x_m,m)=R^d_{\Theta,m}W_{\{q,k\}}\mathbf x_m,\qquad \mathbf q_m^\top\mathbf k_n=\mathbf x_m^\top W_q^\top R^d_{\Theta,n-m}W_k\mathbf x_n$$
$R^d_{\Theta,m}$ is block-diagonal with $d/2$ $2\times2$ rotation blocks (angle $m\theta_i$), $\Theta=\{\theta_i=10000^{-2(i-1)/d},\ i\in[1,\dots,d/2]\}$, $d$ is even, and $R^d_{\Theta,n-m}=(R^d_{\Theta,m})^\top R^d_{\Theta,n}$ because rotations compose. Since $R$ is orthogonal, vector norms are preserved. Efficient implementation (Eq. 34) uses an element-wise multiply with cos/sin and a pairwise swap-and-negate instead of dense matrix multiplication.

**(d) Long-term decay (Eqs. 35-37):** pairing coordinates, the score is $\mathrm{Re}\sum_{i=0}^{d/2-1}\mathbf q_{[2i:2i+1]}\mathbf k^*_{[2i:2i+1]}e^{i(m-n)\theta_i}$. Abel summation bounds it by $\max_i|h_{i+1}-h_i|\sum_i|S_{i+1}|$ with $S_j=\sum_{i<j}e^{i(m-n)\theta_i}$; the average $\frac1{d/2}\sum|S_i|$ decreases as $|m-n|$ grows for the chosen $\theta_i$ (shown numerically in Fig. 2, not as a closed-form proof).

**(e) Linear attention (Eq. 19):** $\mathrm{Attention}(Q,K,V)_m=\dfrac{\sum_n(R^d_{\Theta,m}\varphi(\mathbf q_m))^\top(R^d_{\Theta,n}\phi(\mathbf k_n))\mathbf v_n}{\sum_n\varphi(\mathbf q_m)^\top\phi(\mathbf k_n)}$; the rotation is applied after the non-negative feature maps and the denominator is left unrotated to avoid division by zero.

## 4. Method / architecture / algorithm
1. Compute $\mathbf q=W_q\mathbf x$, $\mathbf k=W_k\mathbf x$ as usual.
2. For each token position $m$, rotate each consecutive coordinate pair of $\mathbf q$ and $\mathbf k$ by $m\theta_i$; leave the values $\mathbf v$ unrotated.
3. Compute standard softmax attention with the rotated queries and keys; no additive position embedding is used.
4. Experiments (Sec. 4): WMT14 EN-DE in fairseq; BERT-base replacement pre-trained on BookCorpus + Wikipedia (batch 64, max length 512, 100k steps, AdamW lr 1e-5); GLUE fine-tuning; Performer with RoPE on Enwik8; a Chinese RoFormer pre-trained on about 34GB with multi-stage lengths up to 1536.

## 5. Achievements
- WMT14 EN-DE BLEU 27.5 vs 27.3 for Transformer-base (Table 1).
- BERT vs RoFormer pre-training: faster MLM loss convergence (Fig. 3 left, qualitative).
- Performer + RoPE on Enwik8 converges faster to lower loss (Fig. 3 right).
- GLUE (Table 2): MRPC 89.5 vs 88.9, STS-B 87.0 vs 85.8, QQP 86.4 vs 71.2; but SST-2 90.7 vs 93.5, QNLI 88.0 vs 90.5, MNLI 80.2/79.8 vs 84.6/83.4. The paper says RoFormer "significantly outperform[s] BERT in three out of six".
- Chinese long text (CAIL2019-SCM, Table 5): RoFormer-1024 test 69.79% vs RoFormer-512 68.29% and WoBERT-512 68.10%; the paper reports a 1.5% absolute improvement over WoBERT at 1024 tokens.
- Enables relative position encoding in linear attention (Sec. 3.3), which prior additive schemes did not.

## 6. Limitations
**Stated by the authors:** no thorough explanation of why RoPE converges faster than other position schemes, nor why it works better on long texts despite the long-term-decay property being shared with other methods; the model still needs substantial hardware for pre-training (Sec. 4.5.4).
**Seen in hindsight (hindsight):** Gains in this paper's own experiments are modest or mixed (BLEU +0.2; GLUE worse on 3 of 6 tasks), and the BERT baseline numbers in Table 2 appear to be the original BERT results while RoFormer is evaluated on the validation set under the authors' own setup, so the comparison is not strictly controlled. The huge QQP gap (86.4 vs 71.2) is suspicious for that reason. Rotary embeddings do not extrapolate cleanly past the training length without later fixes (e.g. position interpolation). The decay claim is shown numerically, not proved for arbitrary q and k.

## 7. Place in the lineage
- **Builds on:** `transformer2017` (sinusoidal encoding, Eq. 4 here), `bert2018` (baseline), relative-position methods (Shaw et al., Transformer-XL, T5, DeBERTa), linear attention (Katharopoulos; Performer).
- **Led to:** `llama2023` and most later open decoder-only LLMs adopt rotary embeddings (hindsight; the LLaMA paper is in the set but its use of RoPE was not checked here), `flashattn2022` kernels commonly fuse it (hindsight).
- Single idea added: encode position by rotating query/key coordinate pairs so that attention scores depend only on relative offset, with no added position vector.

## 8. Verification notes
The paper is inconsistent on the frequency definition: Sec. 3.2.2 writes $\theta_i=10000^{-2(i-1)/d}$ for $i\in[1,d/2]$, Sec. 3.3 writes $10000^{-2i/d}$; same base and spacing, differing in index offset. Eq. 16 in the extracted text is garbled; I restated it from the surrounding derivation (it equals $\mathbf x_m^\top W_q^\top R^d_{\Theta,n-m}W_k\mathbf x_n$ as printed). The arXiv ID says 2021 but the `papers.tsv` lists year 2023 (v5 date); the original posting date is not in the text. The "Led to" notes on LLaMA and FlashAttention are hindsight and not verified from these texts.
