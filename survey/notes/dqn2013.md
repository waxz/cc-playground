# Playing Atari with Deep Reinforcement Learning
**Mnih, Kavukcuoglu, Silver, Graves, Antonoglou, Wierstra, Riedmiller (DeepMind Technologies), arXiv:1312.5602v1, Dec 2013 (NIPS Deep Learning Workshop version)** · **Key:** `dqn2013` · **OpenAlex citations:** 17421 · **Era:** rl
**Read status:** full text. Note: this covers only the 2013 arXiv workshop paper. The later Nature 2015 paper ("Human-level control through deep reinforcement learning") is a different paper (adds a separate target network, 49 games, etc.) and is not summarised here.

## 1. Problem and motivation
Deep learning had worked on vision and speech with large labelled datasets, but RL must learn from a scalar reward that is sparse, noisy and delayed (Sec. 1). RL data is also highly correlated across consecutive states, and the data distribution shifts as the policy changes, both of which violate usual deep-learning assumptions. Earlier RL on Atari relied on hand-engineered features with linear function approximation (Sec. 3), and combining Q-learning with non-linear approximators was known to risk divergence.

## 2. Core idea in one paragraph
Train a convolutional network that takes the last four preprocessed screen frames and outputs one Q-value per action, updating it with Q-learning by SGD. The key trick is experience replay: store past transitions in a big memory and train on random minibatches from it, instead of learning from the latest consecutive frames. Like shuffling a deck of flashcards rather than studying them in the order you met them, this breaks correlations and smooths the training distribution over many past behaviours. The same architecture and hyperparameters are used on all seven games, learning from raw pixels, reward and terminal signal only.

## 3. The mathematics
**Return and optimal value (Sec. 2):** $R_t=\sum_{t'=t}^{T}\gamma^{t'-t}r_{t'}$, $\;Q^*(s,a)=\max_\pi \mathbb{E}[R_t\mid s_t=s,a_t=a,\pi]$.
Symbols: $r_t$ reward (change in game score), $\gamma$ discount, $T$ termination step, $s_t=x_1,a_1,\dots,a_{t-1},x_t$ the action/observation sequence used as state, $\pi$ policy.

**Bellman equation (Eq. 1):**
$$Q^*(s,a)=\mathbb{E}_{s'\sim\mathcal{E}}\big[r+\gamma\max_{a'}Q^*(s',a')\mid s,a\big]$$
$\mathcal{E}$ is the emulator, $s'$ next sequence, $a'$ next action. If the optimal values at the next step were known, the best action maximises $r+\gamma Q^*(s',a')$; iterating this converges to $Q^*$ for tabular value iteration.

**Loss (Eq. 2):**
$$L_i(\theta_i)=\mathbb{E}_{s,a\sim\rho(\cdot)}\big[(y_i-Q(s,a;\theta_i))^2\big],\quad y_i=\mathbb{E}_{s'\sim\mathcal{E}}\big[r+\gamma\max_{a'}Q(s',a';\theta_{i-1})\mid s,a\big]$$
$\theta_i$ network weights at iteration $i$, $\rho$ the behaviour distribution over sequences and actions, $y_i$ the bootstrapped target computed with the previous (fixed) weights $\theta_{i-1}$. Unlike supervised targets, the targets depend on the weights.

**Gradient (Eq. 3):**
$$\nabla_{\theta_i}L_i(\theta_i)=\mathbb{E}\big[\big(r+\gamma\max_{a'}Q(s',a';\theta_{i-1})-Q(s,a;\theta_i)\big)\nabla_{\theta_i}Q(s,a;\theta_i)\big]$$
The target is treated as constant when differentiating. Replacing expectations with single samples gives standard online Q-learning; the model-free, off-policy character follows because it learns about the greedy policy while following an $\epsilon$-greedy behaviour.

**Algorithm 1 target:** $y_j=r_j$ for terminal $\phi_{j+1}$, else $r_j+\gamma\max_{a'}Q(\phi_{j+1},a';\theta)$. Note Algorithm 1 uses the current $\theta$ in the target (no separate target network in this paper).

## 4. Method / architecture / algorithm
1. Preprocess: RGB to grayscale, downsample to 110x84, crop 84x84; $\phi$ stacks the last 4 frames (Sec. 4.1).
2. Network: conv 16 filters 8x8 stride 4 + ReLU; conv 32 filters 4x4 stride 2 + ReLU; FC 256 ReLU; linear output with one unit per action (4 to 18 actions). One forward pass gives all Q-values.
3. Act $\epsilon$-greedily; store $(\phi_t,a_t,r_t,\phi_{t+1})$ in replay memory $D$ of the last $N$ transitions (one million most recent frames).
4. Sample uniform random minibatches (size 32) and take an RMSProp gradient step on the squared error.
5. Settings (Sec. 5): $\epsilon$ annealed linearly 1 to 0.1 over the first million frames then fixed at 0.1; 10 million training frames; frame skip $k=4$ ($k=3$ for Space Invaders so lasers are visible, the only per-game difference); rewards clipped to +1/0/-1 during training only.

## 5. Achievements
- Table 1 (average score, $\epsilon=0.05$): DQN gets B. Rider 4092, Breakout 168, Enduro 470, Pong 20, Q*bert 1952, Seaquest 1705, Space Invaders 581, versus Sarsa 996/5.2/129/-19/614/665/271 and Contingency 1743/6/159/-17/960/723/268. Best single episodes: 5184/225/661/21/4500/1740/1075.
- Beats the best prior learning methods on all seven games, and beats HNeat on six of seven (not Space Invaders: HNeat Best 1720 vs DQN Best 1075) (Sec. 5.3).
- Beats the expert human on Breakout (168 vs 31), Enduro (470 vs 368), Pong (20 vs -3); near human on Beam Rider (4092 vs 7456 stated as "close"); far from human on Q*bert, Seaquest, Space Invaders.
- Stability: no divergence reported in any experiment; average predicted Q rises more smoothly than average reward (Fig. 2, Sec. 5.1). Fig. 3 shows the value function tracking events in Seaquest.

## 6. Limitations
**Stated by the authors:** replay memory of size $N$ overwrites with recent transitions and samples uniformly, so it does not prioritise important transitions (Sec. 4); reward clipping cannot distinguish reward magnitudes (Sec. 5); no theoretical convergence guarantee (Sec. 5.1); weak on games needing strategies over long time scales (Q*bert, Seaquest, Space Invaders).
**Seen in hindsight (hindsight):** only seven games; evaluation noisy and compared to hand-reported human scores; the target uses the same network as the online one, a source of instability later addressed by target networks; max-operator overestimation bias (later Double DQN); sample inefficiency (10M frames per game); a separate agent is trained per game, not one multi-game agent.

## 7. Place in the lineage
- **Builds on:** Q-learning (Watkins and Dayan 1992), TD-Gammon (Tesauro 1995), neural fitted Q-iteration (Riedmiller 2005), experience replay (Lin 1992, cited as [13]), ALE (Bellemare et al.), `alexnet2012`-style GPU convnets (the paper uses the GPU convolution code of [11]).
- **Led to (hindsight):** `a3c2016`, `ddpg2015` (replay plus target networks for continuous actions), `alphago2016`, later Nature DQN, Double/Dueling/Prioritised DQN, Rainbow, and model-based Atari agents such as `simple2019`, `muzero2019`.
- **One idea:** stabilise deep Q-learning from pixels with experience replay and a convnet outputting all action values.
