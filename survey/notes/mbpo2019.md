# When to Trust Your Model: Model-Based Policy Optimization
**Janner, Fu, Zhang, Levine (UC Berkeley), NeurIPS 2019 (arXiv:1906.08253v3)** · **Key:** `mbpo2019` · **OpenAlex citations:** 772 · **Era:** wm
**Read status:** full text of the main paper (Sections 1-7) and the hyperparameter table; proofs in the Appendix not read. The hyperparameter table (Appendix C, Table 1) is badly garbled by extraction, so only values that were unambiguous are quoted.

## 1. Problem and motivation
Model-based RL is data efficient but "model accuracy acts as a bottleneck to policy quality", so it usually ends below model-free asymptotic performance. Existing methods either lack improvement guarantees, or, where theory exists (Sun et al. 2018, Luo et al. 2019), the bounds are so pessimistic they never justify using a model. Methods that roll the model out from the initial state for the whole task horizon suffer compounding error and are often evaluated on truncated, shortened benchmarks (Sec. 1, 5).

## 2. Core idea in one paragraph
Use the learned model only for short bursts. Instead of simulating whole episodes from the start state, branch many short rollouts (as short as one step) from states that were actually visited in the real replay buffer, and feed those synthetic transitions, together with real ones, to a strong off-policy learner (SAC). Because the rollouts start from real states and are short, model error does not compound much, yet the large volume of cheap synthetic data lets the policy take many more gradient steps per real sample. The theory explains why: if model error grows only slowly with how far the policy moves from the data-collecting policy, a small but nonzero rollout length is the optimal trade-off. Analogy: use the model as a short-range flashlight from where you actually stand, not a map of the entire cave.

## 3. The mathematics
**(a) Return bound, full model rollouts (Theorem 4.1, Eq. 1).**
$$\eta[\pi]\ \ge\ \hat\eta[\pi]-\Big[\frac{2\gamma r_{\max}(\epsilon_m+2\epsilon_\pi)}{(1-\gamma)^2}+\frac{4r_{\max}\epsilon_\pi}{1-\gamma}\Big]\ \triangleq\ \hat\eta[\pi]-C(\epsilon_m,\epsilon_\pi)$$
| Symbol | Meaning |
|---|---|
| $\eta[\pi]$ | true expected discounted return of $\pi$ in the real MDP |
| $\hat\eta[\pi]$ | return of $\pi$ under the learned model |
| $\epsilon_m=\max_t\mathbb E_{s\sim\pi_{D,t}}[D_{TV}(p\|p_\theta)]$ | model generalization error on the data-collecting policy's states |
| $\epsilon_\pi\ge\max_sD_{TV}(\pi\|\pi_D)$ | policy shift between iterations |
| $\gamma, r_{\max}$ | discount and maximum reward |

If the policy improves under the model by more than $C$, true improvement is guaranteed. The $(1-\gamma)^{-2}$ factor is the compounding of model error over full-length rollouts.

**(b) Branched rollouts (Theorem 4.2, Eq. 2).** With $k$-step rollouts branched from states of the previous policy's distribution:
$$\eta[\pi]\ge\eta^{branch}[\pi]-2r_{\max}\Big[\frac{\gamma^{k+1}\epsilon_\pi}{(1-\gamma)^2}+\frac{\gamma^k+2}{1-\gamma}\epsilon_\pi+\frac{k}{1-\gamma}(\epsilon_m+2\epsilon_\pi)\Big]$$
One term shrinks exponentially in $k$ and another grows linearly. Taken literally the bound is maximized at $k=0$ (no model), because $\epsilon_m$ is assumed to grow as $\epsilon_m+2\epsilon_\pi$ with no generalization assumptions.

**(c) Empirical model generalization (Theorem 4.3, Eq. 3 and surrounding text).** Measure model error on the *current* policy's distribution, $\epsilon_{m'}\approx\epsilon_m+\epsilon_\pi\,\frac{d\epsilon_{m'}}{d\epsilon_\pi}$ (linear in policy shift, slope estimated empirically, Fig. 1b). Replacing $\epsilon_m+2\epsilon_\pi$ by $\epsilon_{m'}$:
$$\eta[\pi]\ge\eta^{branch}[\pi]-2r_{\max}\Big[\frac{\gamma^{k+1}\epsilon_\pi}{(1-\gamma)^2}+\frac{\gamma^k\epsilon_\pi}{1-\gamma}+\frac{k}{1-\gamma}\epsilon_{m'}\Big]$$
Now $k^*=\arg\min_k[\dots]>0$ for sufficiently low $\epsilon_{m'}$, so the theory actually motivates model usage. Models trained on more data both fit better and generalize better to nearby policies (Fig. 1).

**(d) Model and policy.** The model is a bootstrap ensemble of probabilistic networks $p^i_\theta(s_{t+1},r|s_t,a_t)=\mathcal N(\mu^i_\theta,\Sigma^i_\theta)$ (diagonal covariance); one ensemble member is picked uniformly at random per prediction. Policy: SAC with $J_\pi(\phi,\mathcal D)=\mathbb E_{s_t\sim\mathcal D}[D_{KL}(\pi\|\exp\{Q^\pi-V^\pi\})]$.

## 4. Method / architecture / algorithm
Algorithm 2 (Sec. 5):
1. Train the ensemble $p_\theta$ on the real data $\mathcal D_{env}$ by maximum likelihood.
2. For $E$ environment steps: act with $\pi_\phi$ in the real environment and add to $\mathcal D_{env}$; then perform $M$ model rollouts, each sampling $s_t$ uniformly from $\mathcal D_{env}$ and rolling out $k$ steps with $\pi_\phi$ through the model, adding to $\mathcal D_{model}$.
3. Do $G$ SAC updates on $\mathcal D_{model}$.
Design choices (Appendix C Table 1, partially legible): ensemble size 7; 1000 environment steps per epoch; 400 model rollouts per environment step; $G$ of 20 to 40 policy updates per environment step ("between 20 and 40" per Sec. 5, far more than typical stable model-free values); rollout length $k$ increased linearly over epochs on most tasks (Hopper: 1 to 15, Sec. 6.2). Full-length (1000-step) benchmarks, no access to the true reward function.

## 5. Achievements
- Fig. 2 (MuJoCo, 5 trials): MBPO matches asymptotic performance of SAC and PPO, and learns faster than model-based baselines PETS, STEVE and SLBO; e.g. on Ant it reaches at 300 thousand steps the performance SAC reaches at 3 million steps; on Hopper and Walker2d it needs the equivalent of 14 and 40 minutes of real-time simulation (Sec. 6.1). It learns Ant, a higher-dimensional task where purely model-based PETS has problems.
- Ablations (Fig. 3): SAC with the same high update ratio but no model cannot match it; one-step model rollouts retain most of the benefit; 200-step rollouts work but worse, 500-step rollouts "too inaccurate"; one-step value expansion (MVE-like) is also competitive but MBPO is better.
- Model exploitation (Fig. 4c): on Hopper the policy's returns under the model and the true environment are highly correlated, and model returns tend to underestimate real returns, so short rollouts avoid exploitation.

## 6. Limitations
**Stated by the authors:** the monotonic-improvement bound taken literally recommends no model usage ($k=0$), needing the empirically estimated linear generalization assumption; the bound is "overly pessimistic"; accumulated error in long rollouts is visible (Fig. 4b), and 500-step rollouts fail; combining value expansion with MBPO showed no gains in preliminary tests.
**Seen in hindsight (hindsight):** the generalization slope is estimated from data (not guaranteed); only state-based, low-dimensional MuJoCo tasks with fully observed states and a learned reward, no pixels; ensembles of 7 networks and 20-40 updates per step make it computationally heavy per environment sample; later work (e.g. offline model-based RL) revisited model exploitation more carefully.

## 7. Place in the lineage
- **Builds on:** `sac2018` (policy learner), Dyna (Sutton 1990), PETS probabilistic ensembles (Chua et al. 2018), model-based value expansion/STEVE, `trpo2015`-style monotonic improvement analysis; `ppo2017` as a baseline.
- **Led to:** (hindsight) short-branched-rollout data augmentation became a standard recipe in model-based and offline RL (e.g. MOPO-style methods); related to latent imagination approaches such as `dreamer2019` which also optimize policies on model-generated trajectories.
- **Single idea added:** short model rollouts branched from real replay-buffer states, with theory showing when a nonzero rollout length is justified.
