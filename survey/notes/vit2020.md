# An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale
**Authors, venue, year:** Dosovitskiy, Beyer, Kolesnikov, Weissenborn, Zhai, Unterthiner, Dehghani, Minderer, Heigold, Gelly, Uszkoreit, Houlsby (Google Research, Brain Team); ICLR 2021 (arXiv 2010.11929) · **Key:** `vit2020` · **OpenAlex citations:** 72389 · **Era:** tf
**Read status:** full text (main body read in full; appendix equations located via search; remaining appendix tables not read)

## 1. Problem and motivation
By 2020 the Transformer was the default architecture in NLP, and models above 100B parameters showed no sign of saturating (Sec. 1). In vision, convolutional networks still dominated large-scale recognition. Earlier attempts to use attention in vision either bolted it onto CNNs or used specialised attention patterns (local windows, sparse, axial) that "have not yet been scaled effectively on modern hardware accelerators" (Sec. 1-2). The question was whether a plain Transformer, with almost no image-specific machinery, can match CNNs if given enough data.

## 2. Core idea in one paragraph
Cut the image into a grid of fixed-size patches (e.g. 16x16 pixels), flatten each patch, linearly project it to a vector, and treat the resulting sequence exactly like a sentence of word tokens fed to a standard Transformer encoder. A learnable "class" token (as in BERT) is prepended and its final state is used for classification. The architecture deliberately lacks the CNN priors of locality and translation equivariance, so on mid-sized data it underperforms ResNets; but when pre-trained on 14M-300M images the paper finds that "large scale training trumps inductive bias" (Sec. 1). Analogy: instead of giving the network a magnifying glass that slides over the image, give it a mosaic of tiles and let attention work out which tiles relate.

## 3. The mathematics
**Eqs. (1)-(4), the ViT forward pass (Sec. 3.1):**
$$z_0=[x_{class};x_p^1E;\dots;x_p^NE]+E_{pos},\quad E\in\mathbb{R}^{(P^2\cdot C)\times D},\;E_{pos}\in\mathbb{R}^{(N+1)\times D}$$
$$z'_\ell=\mathrm{MSA}(\mathrm{LN}(z_{\ell-1}))+z_{\ell-1},\qquad z_\ell=\mathrm{MLP}(\mathrm{LN}(z'_\ell))+z'_\ell,\quad \ell=1\dots L,\qquad y=\mathrm{LN}(z_L^0)$$

| Symbol | Meaning |
|---|---|
| $x\in\mathbb{R}^{H\times W\times C}$ | input image; $(H,W)$ resolution, $C$ channels |
| $x_p\in\mathbb{R}^{N\times(P^2 C)}$ | flattened patches; $(P,P)$ patch size; $N=HW/P^2$ is the sequence length |
| $E$ | trainable linear patch projection to width $D$ |
| $x_{class}$ | learnable class token ($z_0^0$); its output $z_L^0$ is the image representation $y$ |
| $E_{pos}$ | learnable 1D position embeddings |
| MSA, MLP, LN | multi-head self-attention, 2-layer MLP with GELU, LayerNorm (pre-norm, applied before every block) |
| $L$ | number of layers |

Meaning: patches become tokens, positions are learned, and a pre-norm residual Transformer processes them; the paper states it follows the original Transformer "as closely as possible" so NLP implementations transfer.

**Eqs. (5)-(8), self-attention (Appendix A):**
$$[q,k,v]=zU_{qkv},\quad A=\mathrm{softmax}(qk^\top/\sqrt{D_h}),\quad SA(z)=Av,\quad \mathrm{MSA}(z)=[SA_1(z);\dots;SA_k(z)]U_{msa}$$
Here $U_{qkv}\in\mathbb{R}^{D\times 3D_h}$, $A\in\mathbb{R}^{N\times N}$ are the attention weights, $k$ is the number of heads, $D_h=D/k$ keeps compute constant, $U_{msa}\in\mathbb{R}^{kD_h\times D}$. Every token attends to every other, so cost is quadratic in $N$, which is why patches (not pixels) are used: the Sec. 2 argument is that per-pixel attention "does not scale to realistic input sizes".

**Fine-tuning at higher resolution (Sec. 3.2):** keep patch size fixed so $N$ grows; 2D-interpolate the pre-trained position embeddings according to their location in the original image. The paper notes this and patch extraction are "the only points" where 2D structure is manually injected.

## 4. Method / architecture / algorithm
1. Split image into $P\times P$ patches, flatten, project with $E$; prepend class token; add $E_{pos}$.
2. Run $L$ pre-norm Transformer encoder layers (Eqs. 2-3).
3. Pre-train with a one-hidden-layer MLP head; at fine-tuning replace by a zero-initialised $D\times K$ linear layer.
4. Variants (Table 1): ViT-Base 12 layers, D=768, MLP 3072, 12 heads, 86M params; ViT-Large 24/1024/4096/16, 307M; ViT-Huge 32/1280/5120/16, 632M. "ViT-L/16" = Large with 16x16 patches; smaller patches mean longer sequences and more compute.
5. Training: Adam ($\beta_1=0.9,\beta_2=0.999$), batch 4096, weight decay 0.1, linear warmup and decay; fine-tuning with SGD+momentum, batch 512; ImageNet numbers fine-tuned at 512 (ViT-L/16) and 518 (ViT-H/14) with Polyak averaging 0.9999 (Sec. 4.1).
6. Also a hybrid: feed ResNet feature maps (patch size 1x1) into the Transformer.
7. Data: ImageNet (1.3M images), ImageNet-21k (14M), JFT-300M (303M images, 18k classes).

## 5. Achievements
- Table 2: ViT-H/14 (JFT) reaches 88.55 ± 0.04 ImageNet, 90.72 ReaL, 99.50 CIFAR-10, 94.55 CIFAR-100, 97.56 Pets, 99.68 Flowers, 77.63 VTAB (19 tasks), versus BiT-L (ResNet152x4) 87.54 ImageNet and 76.29 VTAB, and Noisy Student 88.4/88.5 ImageNet.
- Compute (Table 2): 2.5k TPUv3-core-days for ViT-H/14 and 0.68k for ViT-L/16, versus 9.9k for BiT-L and 12.3k for Noisy Student. ViT-L/16 pre-trained on ImageNet-21k gets 85.30 ImageNet at 0.23k core-days.
- Sec. 4.4 / Fig. 5: ViT uses roughly 2-4x less compute than ResNets for equal transfer performance (average over 5 datasets); hybrids help only at small budgets; no saturation observed.
- Sec. 4.3 / Figs. 3-4: with small pre-training sets (ImageNet, 9M JFT subset) ResNets win; with 90M+ images ViT wins.
- Sec. 4.5: learned position embeddings encode 2D distance and row/column structure; some heads attend globally even in the lowest layers.
- Sec. 4.6: masked-patch self-supervision gives ViT-B/16 79.9% ImageNet, +2% over scratch but 4% behind supervised pre-training.

## 6. Limitations
**Stated by the authors:** Needs large pre-training data; on ImageNet alone it is "a few percentage points below ResNets of comparable size" (Sec. 1). Detection and segmentation are not yet addressed; self-supervised pre-training still lags supervised by a large gap; further scaling is left for future work (Sec. 5). Compute comparisons may be affected by schedule, optimiser and weight decay, not only architecture (Sec. 4.2).
**Seen in hindsight (hindsight):** The strongest results depend on the proprietary JFT-300M, so they were not reproducible by outsiders. Quadratic attention in patch count limits resolution. Plain ViT has a single-scale feature map, which later hierarchical designs addressed for dense tasks. Later work showed data-efficient training recipes and self-supervision close much of the data gap.

## 7. Place in the lineage
- **Builds on:** `transformer2017` (architecture), `bert2018` ([class] token, model sizes, masked prediction), `resnet2015` and BiT/Noisy Student baselines, `gpt3_2020` scaling motivation, `adam2014`, `layernorm2016`.
- **Led to:** `clip2021` (ViT image encoder), `flamingo2022`, `llava2023`, `dit2022` (transformer on latent patches), `ijepa2023`, `vjepa2_2025`, and the vision encoders in `rt2_2023`, `openvla2024`, `pi0_2024` (hindsight).
- **Single idea added:** an image is just a sequence of patch tokens, so an unmodified Transformer plus scale replaces convolutions.
